### 4. Работа с формой

#### Контекст

Для работы с формами в React чаще всего используют две библиотеки: **Formik** и **react-hook-form**.

Различается и сам подход. Formik хранит значения полей в состоянии React, поэтому ввод в любое поле перерисовывает форму. React-hook-form работает с неконтролируемыми полями (через `ref`) и перерисовывает только то, что действительно изменилось.

#### Решение

Для работы с формой используем **react-hook-form**.

Правила использования:

1. Значения формы описываются интерфейсом `<Форма>Values` (см. ADR 8) и передаются в `useForm` как generic.
2. Начальные значения задаются через `defaultValues`.
3. Для нативных полей используем `register`, для контролируемых компонентов UI-кита — `Controller`.
4. Если для валидации используется схема, подключаем её через `resolver`.
5. Подписываться на значения полей нужно через `useWatch`, а не `watch`: `watch` не отслеживается React Compiler.

```tsx
import {Controller, useForm} from 'react-hook-form';

interface LoginFormValues {
  email: string;
  role: string;
}

interface LoginFormProps {
  onSubmit: (values: LoginFormValues) => void;
}

export const LoginForm = ({onSubmit}: LoginFormProps) => {
  const {
    register,
    control,
    handleSubmit,
    formState: {errors},
  } = useForm<LoginFormValues>({defaultValues: {email: '', role: 'viewer'}});

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      {/* нативное поле — register */}
      <input {...register('email', {required: 'Введите email'})} />
      {errors.email && <p role="alert">{errors.email.message}</p>}

      {/* контролируемый компонент UI-кита — Controller */}
      <Controller
        name="role"
        control={control}
        render={({field}) => <Select {...field} options={ROLES} />}
      />

      <button type="submit">Войти</button>
    </form>
  );
};
```

##### Когда библиотека не нужна

Форму из одного-двух полей без сложной валидации можно написать на нативном `<form>` и `useState`: подключать библиотеку ради этого не требуется.

##### Рассмотренные варианты

|                    | Formik                                          | react-hook-form                                            |
| ------------------ | ----------------------------------------------- | ---------------------------------------------------------- |
| Подход             | контролируемые поля, значения в состоянии React | неконтролируемые поля, подписка на нужные значения         |
| Перерисовки        | ввод в любое поле перерисовывает форму          | перерисовывается только затронутое                         |
| Валидация по схеме | через `validationSchema`                        | через `resolver`                                           |
| TypeScript         | generic `Formik<Values>`                        | generic `useForm<Values>`, имена полей проверяются по типу |

#### Последствия

- Единообразие кода и подходов во всех формах проекта.
- Меньше лишних перерисовок на больших формах.
- Для полей UI-кита нужны обёртки через `Controller`.
