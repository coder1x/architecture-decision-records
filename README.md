## Как читать АДР

Все документы устроены одинаково:

1. **Контекст:** какая проблема возникла и почему нужны единые правила.
2. **Решение:** что мы приняли, с примерами кода (правильными и неправильными).
3. **Последствия:** что получаем и какую цену платим.

Многие АДР ссылаются друг на друга (например, «см. ADR 8»), поэтому номер в тексте всегда соответствует номеру в таблице выше.

## Как добавить новый АДР

1. Возьмите следующий свободный номер (сейчас `016`).
2. Назовите файл по шаблону `016_краткое_название.md`: трёхзначный номер, слова через подчёркивание.
3. Первой строкой напишите заголовок `### 16. Название решения`, затем разделы **Контекст**, **Решение**, **Последствия**.
4. Добавьте строку в нужный раздел этого README.
